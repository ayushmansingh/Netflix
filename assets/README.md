# Assets

Drop your partner's photos and short video clips here, then update the paths in `../config.js` to match.

## What you need

| File (suggested name) | What it is | Recommended size |
| --- | --- | --- |
| `avatar.jpg` | Partner's face for the profile select + PIN screen | square, 400x400+ |
| `hero.jpg` | Big featured banner at the top of the home page | landscape, 1920x1080 |
| `memory-1.jpg` ... `memory-4.jpg` | Cards in "Continue Watching for You" | landscape, 16:9 |
| `top-1.jpg` ... `top-6.jpg` | Cards in "Top 10" row | portrait, 2:3 (poster style) |
| `love-1.jpg` ... `love-5.jpg` | Cards in "Because You Loved Me" | landscape, 16:9 |
| `trend-1.jpg` ... `trend-5.jpg` | Cards in "Trending Now" | landscape, 16:9 |
| `list-1.jpg` ... `list-3.jpg` | Cards in "My List" | landscape, 16:9 |
| `profile-kids.png`, `profile-guest.png` | Decoy profiles | square |

## Videos

Any field that takes an `image` will also accept a video file (`.mp4`, `.webm`, `.mov`). It will autoplay muted and loop, exactly like Netflix's hover previews. Keep clips short (5-15s) and small (<5MB) for snappy loading.

## Tips

- 16:9 thumbnails look best — Netflix card aspect ratio.
- For the "Top 10" row use vertical poster-style images (2:3).
- The hero image gets darkened by gradients on the left and bottom — pick a photo where the focal point is centered or right-of-center so the title text doesn't cover their face.
